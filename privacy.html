Privacy Policy

Last updated: 16 October 2026

TolieFlick is an independent Windows desktop application currently in development. This page describes the intended handling of information by the application and its optional integrations. As the project evolves, this policy may be updated to reflect its actual behavior.

Local media and game libraries

TolieFlick is designed to read folders selected by the user to organise local movies, TV series and games. The application may store library indexes, metadata, playback progress and preferences on the user's computer. Local library data is not intended to be uploaded to a TolieFlick-operated server.

Third-party integrations

Optional integrations may connect to YouTube, Twitch and third-party metadata services. When you choose to connect an account, TolieFlick may request the permissions necessary to display your subscriptions, followed channels or other relevant information. Requests to these services are governed by their own privacy policies and terms.

For YouTube, the planned integration uses read-only access to retrieve information relevant to the user's subscribed channels and videos. TolieFlick does not intend to upload videos or modify YouTube account content. The YouTube integration is subject to API access and may not be available at all times.

Authentication and credentials

Connected-account authentication information is intended to be stored locally using the operating system's credential storage where supported. Do not share authentication tokens, API keys or client-secret files publicly.

Website

This website is a static project-information site hosted on GitHub Pages. GitHub may process technical information associated with website visits under its own privacy practices. This site does not currently provide account registration or a contact form.

Choices and access

Online account connections are optional. You can choose not to connect third-party accounts. The application's connection-management and data-removal behavior will be documented more fully as development progresses.

Contact

For enquiries about the project or this policy, visit the TolieFlick GitHub repository. A dedicated privacy contact method will be added before any broader public release.

Third-party policies

See the Google Privacy Policy, YouTube Terms of Service, Twitch Privacy Notice, and GitHub Privacy Statement.
