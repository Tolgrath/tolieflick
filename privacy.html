YOUR PRIVACY

Privacy Policy

Last updated: 16 October 2026

TolieFlick is an independently developed Windows desktop application intended primarily for personal use. This policy describes the application's current design and known integrations. As development continues, this policy may be revised to reflect verified behavior and new features.

Local media and game libraries

TolieFlick lets users select folders containing local movies, TV series and games. It may store library indexes, media metadata, playback progress and application preferences on the user's computer. TolieFlick does not operate a cloud library server for uploading those local media files.

Optional third-party services

TolieFlick can connect to external services, including YouTube and Twitch, when the user chooses to authorize a connection. The application also uses external metadata services to look up information such as titles and artwork. These requests necessarily send relevant request information to the applicable service, which processes it under its own terms and privacy policy.

YouTube integration

If the user connects a Google account, TolieFlick requests the read-only YouTube permission (https://www.googleapis.com/auth/youtube.readonly). This permission is used to retrieve YouTube information for display inside the application, such as subscribed channels and associated video or activity information.

TolieFlick does not use this permission to upload videos, publish comments, modify subscriptions or change YouTube account content. YouTube functionality depends on the availability of Google's APIs and applicable API quotas.

Twitch integration

If the user connects Twitch, TolieFlick uses the authorized connection to display relevant Twitch content, such as followed channels, streams and videos, within the application. Twitch access is optional.

Authentication and credentials

TolieFlick is designed to store connected-account authentication credentials locally using the operating system's credential storage where supported. Credentials are used to authenticate requests to the services the user has connected. Do not publish authentication tokens, API keys or OAuth client-secret files.

Disconnecting accounts and revoking access

TolieFlick includes Disconnect YouTube and Disconnect Twitch controls in its settings. Users can use these controls to disconnect the respective integrations within the application.

Users can separately manage or revoke authorization through their provider's account settings. For Google, visit Google Account third-party connections. Disconnecting inside an application does not necessarily revoke an authorization already granted at the provider.

Website

This website is a static project-information site hosted on GitHub Pages. It does not provide user registration or a contact form. GitHub may process technical information associated with website visits according to its own privacy practices.

Your choices

Connecting YouTube or Twitch is optional. Users may choose to use local-library features without connecting those services, and may disconnect connected accounts using the controls described above.

Contact

For questions about TolieFlick or this privacy policy, contact the independent developer, Tolgrath, at tolgrath.orig.ellipsis@gmail.com. You can also visit the TolieFlick GitHub repository.

Third-party policies

See the Google Privacy Policy, YouTube Terms of Service, Twitch Privacy Notice, and GitHub Privacy Statement.
